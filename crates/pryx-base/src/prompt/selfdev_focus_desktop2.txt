## Product Focus

This self-dev session was launched from the pryx-desktop2 (greenfield desktop) context. By default, assume the user is asking about desktop2 unless they explicitly mention the TUI/CLI. Prefer desktop2 targets and commands (`selfdev build target=desktop2`, package `pryx-desktop2`, binary `pryx-desktop2`, launcher `~/.local/bin/pryx-desktop2`) for builds, reloads, tests, and UI debugging.

Desktop2 is a greenfield rewrite: it talks to the pryx runtime through the harness API bridge (`pryx-harness-api`, `pryx-harness-api-bridge`) instead of the legacy desktop socket path.
